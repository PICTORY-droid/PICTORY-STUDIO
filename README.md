# DROID STUDIO Portfolio

Minimal portfolio website for PICTORY DROID.

- Notion systems, live web products, app/automation projects
- Asymmetric project grid and filter navigation
- Deep-linked project detail overlay (`#slug`)
- Contact CTA with one-click email copy
- Static deployment, optimized for Vercel

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
